Setup generators

Usage

npx f3router setup-claude        # wire Claude Code
npx f3router setup-codex         # wire Codex CLI
npx f3router setup-dsh           # wire DeepSeek Harness
npx f3router setup-mimo          # wire MiMo Code
npx f3router setup-atomcode      # wire AtomCode
npx f3router --dry-run setup-claude  # preview without writing
npx f3router setup-claude --model gpt-4o  # pin a model

Every generator (cli/src/tools.ts:52-622) fetches the live catalog, resolves --model against the unfiltered catalog (c942352), backs up existing config with a timestamped copy, merges without clobbering unrelated keys, and writes with 0600.

Zero-persistence launchers

npx f3router launch            # injects F3ROUTER_API_KEY + model into `claude`
npx f3router launch-codex      # injects into `codex --profile NAME`

These do not write config files; they spawn the child process with F3ROUTER_API_KEY/F3ROUTER_MODEL in env only. Useful for ephemeral or shared machines.

f3router doctor

npx f3router doctor

Proves a client's requests reach this gateway (checks routed Authorization header, catalog, live probe).

Common flags

Flag Effect
--dry-run Preview changes without writing; shows diff
--model <id> Pin to a model (resolved against unfiltered catalog)
--profile <name> Named profile (Codex codex --profile NAME, Claude CLAUDE_CONFIG_DIR)
