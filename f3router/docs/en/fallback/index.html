Fallback Domain — Overview & File Index

This domain documents f3router's named fallback-chain system: how chains are stored, how the router resolves the active chain (and refuses when it is empty), how named chains surface to clients as auto:<name>, and how catalog sync interacts with curated chains. The root README.md and OVERVIEW.md index this as the operator's primary mechanism for controlling which models the router may use.
