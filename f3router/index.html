One free LLM endpoint for all your coding agents

f3router gives Claude Code, Codex, Pi, OpenCode and other agents a single OpenAI-compatible /v1 endpoint. It sends each request to a free provider that has quota left, and falls over to the next one when a limit is hit.

How it works

Your agent talks to one endpoint. f3router ranks the free models you have keys for, sends the request to the best one available, and keeps per-key usage so you stay under each free-tier cap.

One endpoint

Point any OpenAI or Anthropic client at /v1. No SDK changes.

Live routing

Requests go to the best free model right now, based on reliability, speed and quota.

Automatic fallback

Rate-limited or failing providers are skipped and cooled down before your agent sees an error.

Your keys, encrypted

Provider keys are stored encrypted on your machine. Nothing is sent to us.

Quick start

  1. Install

    Run the installer from the repository, or download the desktop app from GitHub Releases.

  2. Add a free key

    Add keys from the providers you use (Groq, Cerebras, Gemini and others have free tiers).

  3. Point your agent at f3router

    Set the base URL to http://localhost:<port>/v1 and use the key shown in the app.

FAQ

Is f3router free?

Yes. The code is MIT licensed and runs on your own machine. The providers you connect have their own free-tier limits.

Where do my keys go?

Only to the providers you configure. They are stored encrypted on your machine.

Which agents work with it?

Any tool that accepts an OpenAI-compatible or Anthropic-compatible base URL, including Claude Code, Codex, Pi, OpenCode, Cline and Aider.

Does it hide provider errors?

It retries and falls over to other providers first. Failovers, cooldowns and scores are visible per request in Analytics.
